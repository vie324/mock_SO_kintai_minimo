# SalonOne 改善モック（勤怠 / minimo連携枠）

SalonOne の **打刻・勤怠管理** と **minimo連携枠のモバイル操作** について、
改善案を検証するための UI モック置き場です。

素の HTML 1枚（inline CSS / JS）で作られており、**外部ライブラリもビルドも不要**です。
ファイルをブラウザで開けばそのまま動きます。

各 HTML の**冒頭コメント**に、そのファイル固有の仕様と API 案を書いてあります。
実装に入る前に、まず `claude_code_handoff.md` を読んでください。

## 何を検証するモックか

### minimo連携枠（`minimo_mobile_mock.html`）

現状スマホでは、minimo連携枠はピンクの細い縦バーで**閲覧専用**です。
このモックでは枠をタップで編集モードに入り、ドラッグで移動・上下ハンドルで伸縮、
空き時間の長押しで新規作成ができます。予約や他の枠と重なると赤くなり保存できません。

- 実装定数: `DAY_START=9:00` / `DAY_END=19:00` / `SNAP=15分`
- 時刻はすべて「0:00からの分(int)」で保持し、描画時のみ px へ変換

### 打刻・勤怠管理（`kintai_mock.html`）

現行実装のバグ 5 件（詳細は memo §3-1）への対処案を含みます。

> **最優先: 時間表記の小数バグ**
> 現状 `合計 8h43.7166666666667m` のように小数のまま表示されています。
> API が `work_minutes: 523.7166666666667` を返し、フロントがそのまま描画しているためです。
> **API 側で整数分に丸める**＋**フロントは必ず `fmtHM()` / `fmtJa()` を通す**、の両方で直します。
> このバグは他の改修と切り離して先に出すのが安全です（memo §6 末尾）。

残り 4 件は「退勤未打刻が埋もれる」「スタッフ絞り込みがない」「打刻を修正できない」
「スマホで横スクロールになる」です。いずれもモック側に対処案を実装済みです。

## 実装に進む前に

`claude_code_handoff.md` の **§5 未決事項** に、決めてから実装したい項目を 12 件挙げています。
minimo 枠側 5 件（営業時間外の可否・同期の方向・最小枠の長さなど）、
勤怠側 7 件（所定労働時間の設定単位・休憩の自動控除・深夜割増・日跨ぎ勤務など）です。
ここが決まらないと手戻りになる箇所なので、先に潰してください。

移植時の方針・デザイントークンの対応表・Claude Code への指示文の雛形も
同じメモの §2-6 / §4 / §6 にあります。

## 位置づけ

- ここにあるのは**モック**です。プロダクトのコードではありません
- 表示しているデータはすべてハードコードされたダミーで、通信は一切しません
- CSV 出力だけは実際にファイルを生成します（BOM付き UTF-8）
