SalonOne 改善モック

勤怠管理（PC／スマホ・管理者／打刻者の4画面）と、minimo連携枠のスマホ操作（1画面）の計5画面。 素のHTML＋CSS＋JSで、ビルドも依存ライブラリもなし。下のプレビューは実寸幅で描画したものを縮小しています。

勤怠管理（管理者）2画面 — PC / スマホ

月次の打刻実績を確認・修正・承認する。1ファイルで両対応（1024pxでサイドバー格納、768pxで表→カード）。

管理者・PC1280px 開く
/time-tracking
サイドバー＋KPI5枚＋スタッフ別テーブル。打刻漏れは行ごと赤地。
管理者・スマホ390px 開く
/time-tracking
表を捨ててカードへ。横スクロールなし。

打刻（スタッフ）2画面 — PC / スマホ

出退勤を打刻する。店舗の共用PCからもスタッフのスマホからも同じ画面を使う。

打刻者・PC1280px 開く
/punch
左に打刻ボタン、右に今日のタイムライン。押せるボタンだけ有効。
打刻者・スマホ390px 開く
/punch
1カラム。GPS範囲外なら全ボタンをロック。

minimo連携枠（スマホ）1画面

予約表のピンクの枠を、タップ→ドラッグで移動・伸縮できるようにする。スマホ専用。

minimo連携枠・スマホ390px 開く
/schedule
タップで編集、ドラッグで移動、ハンドルで伸縮、長押しで新規。重複は赤で保存不可。
ファイル構成
  • screens/ … 3ファイル。勤怠の管理者／打刻者はそれぞれ1ファイルでPC・スマホ両対応（＝画面としては4つ）
  • assets/tokens.css … 色などのCSS変数だけ。tailwind.config の theme に1対1で対応する
  • assets/base.css … リセットと共通パーツ（ボタン・カード・タグ・モーダル・トースト）
  • assets/attendance.js … DOMに触らない純粋関数。移植先は utils/attendance.ts
  • assets/mockdata.js … ダミーデータ。移植時はAPIレスポンスに置き換わる
仕様・データモデル案・API案・未決事項は claude_code_handoff.md にまとめてあります。
